# Студия — календарь салона

Закрытый календарь администратора: женский и мужской залы, по три мастера, клиенты и записи. Данные хранятся в Cloudflare D1. Начальная настройка добавляет только шесть условных мастеров; реальные клиенты и записи не создаются автоматически.

Часы: 09:00–20:00, время с шагом 15 минут, календарь с шагом 30 минут. Дата по умолчанию использует Asia/Qyzylorda. Имена мастеров редактируются в разделе «Мастера».

Таблицы: masters, clients, appointments, slots. Уникальный индекс master_day_minute предотвращает пересечения записей даже при одновременном сохранении. Сохранение/перенос записи выполняется атомарным D1 batch; отмена освобождает время.

Доступ ограничен владельцем через Sites. Перед расширением аудитории следует определить роли администраторов и мастеров.

Разработка: pnpm install; pnpm exec drizzle-kit generate; pnpm run build. Миграции локальной базы применяются через Wrangler из dist/server/wrangler.json.
